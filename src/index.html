      Keyboard shortcuts

      Editing

      Enter
      New bullet (context-aware)
      Tab / ⇧Tab
      Indent / outdent
      ⌘↑ / ⌘↓
      Move bullet up / down
      ⌘⇧⌫
      Delete current bullet (and subtree)
      ⌘⏎
      Toggle complete
      ⌘Z / ⌘⇧Z
      Undo / redo

      Navigation

      ↑ / ↓
      Move cursor between bullets
      ⌘.
      Collapse / expand current bullet
      ⌘⇧.
      Collapse / expand all descendants
      ⌘PgDn
      Zoom into current bullet
      ⌘PgUp
      Zoom out one level

      Selection

      Drag
      Select range of bullets
      ⇧Click
      Extend selection to clicked bullet
      ⇧↑ / ⇧↓
      Extend selection by one row
      Esc
      Clear selection

      Clipboard

      ⌘C
      Copy selection (or current subtree) as markdown
      ⌘⇧C
      Copy current bullet subtree as markdown
      ⌘X
      Cut selection (or current subtree)
      ⌘V
      Paste — markdown bullets become children

      Help

      ⌘/
      Show this list
      Esc
      Close this list
